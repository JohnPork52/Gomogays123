# Gomogays123

Секретный deepseek API и небольшой CLI-парсер курса биткоина.

## Возможности

- Получение актуального курса BTC/USD
- Автоматический fallback между источниками: Coinbase, Binance, CoinGecko
- Аккуратный вывод в терминал с цветами (если поддерживается)
- Точные вычисления через `Decimal`

## Запуск

```bash
pip install requests
python3 parser.py
```

Пример вывода:

```
┌────────────────────────────────┐
│   ₿  БИТКОИН / ДОЛЛАР США      │
├────────────────────────────────┤
│  Курс       $67,432.10         │
│  Источник   Coinbase           │
│  Время      17.11.2026 12:08   │
└────────────────────────────────┘
```

## Структура

- `parser.py` — получение и отображение курса BTC
